## step1 · `main.py`（18 行）—— 最小可用

```python
from fastapi import FastAPI                      # 导入框架

app = FastAPI(title="Step 1 最小示例")            # ① 创建应用，title 会显示在 /docs

@app.get("/health")                               # ② 路由：GET /health → health 函数
async def health():
    return {"status": "ok"}                       # ③ 返回 dict → 自动转成 JSON

@app.get("/items/{item_id}")                      # ④ 路径参数：{item_id}
async def read_item(item_id: int):                # ⑤ 类型 int → 自动校验+转换
    return {"item_id": item_id}                   #    传非数字 => 422
```

**要点**
- `app` 是核心对象，uvicorn 加载的就是它。
- `@app.get("/路径")` 注册路由。
- `{item_id}` 是路径参数，冒号 `: int` 声明类型 → 自动校验 + 转 int + 生成 /docs。
- 返回 `dict` → 自动序列化成 JSON。

## step2 · `main.py`（39 行）—— 加校验 + 依赖注入

```python
from typing import Annotated                        # 给类型附加额外信息
from fastapi import Depends, FastAPI, Header, HTTPException
from pydantic import BaseModel                      # Pydantic 数据模型

app = FastAPI(title="Step 2 校验 + 依赖注入")

# ① 依赖函数：做鉴权
def get_current_user(authorization: Annotated[str, Header()] = "Bearer secret"):
    #    ↑ Header() 表示从 HTTP 请求头取 "Authorization" 字段
    token = authorization.removeprefix("Bearer ").strip()   # 去掉 "Bearer " 前缀
    if token != "secret":                                   # 假鉴权：跟固定字符串比
        raise HTTPException(status_code=401, detail="未登录或 token 无效")
    return {"id": 1, "name": "张三"}                        # 通过则返回用户

# ② 把依赖包装成"可注入类型"
CurrentUser = Annotated[dict, Depends(get_current_user)]
#              ↑ 声明：需要 dict 类型，值来自 get_current_user()

# ③ Pydantic 请求体模型
class Item(BaseModel):          # 继承 BaseModel → 自动校验字段
    name: str
    price: float                # 缺 name/price 或类型错 => 422

# ④ POST 接口：body 校验 + 依赖注入 + 响应序列化
@app.post("/items", response_model=Item)   # response_model 约定返回结构
async def create_item(item: Item, user: CurrentUser):  # item 自动解析body; user 自动注入
    return item

# ⑤ 同步 def 路由（走线程池，不占用事件循环）
@app.get("/items/{item_id}")
def read_item(item_id: int, user: CurrentUser):
    return {"item_id": item_id, "creator": user["name"]}
```

**step2 相对 step1 多了什么**
- `BaseModel` → 请求体**自动校验**（缺字段/类型错 → 422）
- `Depends` → **依赖注入**，把鉴权逻辑抽出来复用
- `Header()` → 从 HTTP 请求头取值

**注意**：这里鉴权是**假的**（`== "secret"` 死字符串），step3 才改成真 JWT。

## step3 · 模块化 + 真实 JWT

### `app/config.py` —— 读配置

```python
class Settings(BaseSettings):            # 继承 pydantic-settings
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")
    APP_NAME: str = "My App"             # 从 .env 读，缺失时用默认值
    SECRET_KEY: str = "change-me-in-env" # JWT 密钥（机密！）
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 30
    DEBUG: bool = False
settings = Settings()                    # 全局单例，其它模块用 settings.SECRET_KEY
```

> 好处：配置不再硬编码，改 `.env` 即可；带类型和默认值校验。

### `app/security.py` —— JWT 签发 + 校验（step3 核心升级）

```python
import jwt                         # PyJWT 库
ALGORITHM = "HS256"                # 签名算法

def create_access_token(subject):          # ① 签发 token（登录成功时调用）
    expire = datetime.now(UTC) + timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    payload = {"sub": str(subject), "exp": expire}   # 载荷：用户id + 过期时间
    return jwt.encode(payload, settings.SECRET_KEY, algorithm=ALGORITHM)
    #     ↑ 用密钥签名 → 别人无法伪造

def decode_token(token):                    # ② 校验 token
    return jwt.decode(token, settings.SECRET_KEY, algorithms=[ALGORITHM])
    #     ↑ 验证签名+过期；不对就抛 jwt.InvalidTokenError
```

### `app/dependencies.py` —— 用 JWT 校验取代死字符串

```python
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/login")  # 期望 "Authorization: Bearer <token>"

def get_current_user(token: Annotated[str, Depends(oauth2_scheme)]):
    try:
        payload = decode_token(token)       # ① 验证签名+过期
    except InvalidTokenError:
        raise HTTPException(401, "token 无效或已过期")
    user_id = payload.get("sub")            # ② 从 token 取用户id
    return {"id": user_id, "name": "张三"}  # 真实项目此步会查数据库
CurrentUser = Annotated[dict, Depends(get_current_user)]
```

### `app/routers/login.py` —— 登录接口

```python
@router.post("/login")                       # 最终路径 = /api/v1/login
async def login(form: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = FAKE_USERS.get(form.username)     # 查"用户表"
    if not user or user["password"] != form.password:
        raise HTTPException(401, "用户名或密码错误")
    token = create_access_token(user["id"])  # ① 签发 token
    return TokenResponse(access_token=token) # ② 返回给客户端
```

> 这里用 `OAuth2PasswordRequestForm`，所以 Swagger 的 Authorize 弹窗能直接填用户名密码换 token。

### `app/routers/items.py` —— 业务接口

```python
router = APIRouter(prefix="/items", tags=["items"])   # ① 前缀 /items

@router.post("/", response_model=Item)                 # 最终路径 = /api/v1/items/
async def create_item(item: Item, user: CurrentUser):
    return item

@router.get("/{item_id}")                              # 最终路径 = /api/v1/items/{id}
def read_item(item_id: int, user: CurrentUser):
    return {"item_id": item_id}
```

### `app/api/main.py` —— 汇总路由

```python
api_router = APIRouter()
api_router.include_router(login.router)   # 挂载 login
api_router.include_router(items.router)   # 挂载 items
```

### `app/main.py` —— 入口

```python
app = FastAPI(title=settings.APP_NAME, debug=settings.DEBUG)
app.include_router(api_router, prefix="/api/v1")   # 所有接口挂在 /api/v1 下
```

## 补充 · 常见疑问详解

### 1. `model_config` 后来被使用了吗？

**用了，但不用你手动用。** 它交给 pydantic-settings 在**实例化时自动读取**。

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")
    APP_NAME: str = "My App"
    ...
settings = Settings()   # ← 在这一步，pydantic-settings 自动读 model_config
```

- `env_file=".env"` → 告诉框架去读 `.env` 文件
- `extra="ignore"` → `.env` 里未定义的键忽略，不报错
- **时机**：`settings = Settings()` 那一行
- **谁用**：pydantic-settings 框架内部，你看不到也不用手动访问
- **验证**：`.env` 里 `APP_NAME=Step3 Demo`，`settings.APP_NAME` 读出来就是 `Step3 Demo`

> 结论：`model_config` 是"给框架看的配置声明"，平时不用碰，`settings.XXX` 的值都来自它。

---

### 2. `response_model` 支持哪些形式？

`Item` 不是固定的，`response_model=` 右边可以换：

```python
response_model=Item              # 单个对象
response_model=list[Item]        # 对象数组
response_model=dict              # 任意字典
response_model=str               # 字符串
response_model=Item | None       # 可能是 Item 或 null
response_model=dict[str, Item]   # 按 key 的字典
```

- **`response_model` 控制的是"响应"**（返回给客户端的数据）
- **`item: Item` 控制的是"请求体"**（客户端发来的数据）
- 同一个 `Item` 类可以既做请求模型又做响应模型

> 作用：过滤多余字段、校验返回类型、生成 /docs、类型安全。

### 3. `async def login(form: Annotated[OAuth2PasswordRequestForm, Depends()])` 是自动获得认证信息吗？

**分两层：**
- **自动**：`OAuth2PasswordRequestForm` + `Depends()` 自动**解析** `username` / `password` 表单
- **手动**：判断用户名密码**对不对**、签发 token，是你在函数体里写的

```python
async def login(form: Annotated[OAuth2PasswordRequestForm, Depends()]):
    user = FAKE_USERS.get(form.username)              # 手动：查用户
    if not user or user["password"] != form.password: # 手动：判断密码
        raise HTTPException(401, "用户名或密码错误")
    token = create_access_token(user["id"])           # 手动：签发 token
    return TokenResponse(access_token=token)
```

> 表单解析是自动的；鉴权判断是手动的。

---

### 4. `return TokenResponse(access_token=token)` 直接把 token 组装成完整 response？

对。`TokenResponse(...)` 是调用类创建对象，`access_token=token` 是关键字参数赋值。

```python
class TokenResponse(BaseModel):
    access_token: str
    token_type: str = "bearer"

return TokenResponse(access_token=token)
# → TokenResponse(access_token="eyJ...", token_type="bearer")
# → 再按 response_model=TokenResponse 序列化成 JSON 给前台
# → {"access_token":"eyJ...", "token_type":"bearer"}
```

---

### 5. `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/login")` 什么时候被调用？

- **创建对象时**：只登记 `tokenUrl` 信息，**不发请求**
- **`tokenUrl` 被读取**：Swagger 的 Authorize 弹窗（前端）读它去登录换 token；生成 OpenAPI 文档时读取
- **每次请求**：`Depends(oauth2_scheme)` 从请求头取 `Authorization: Bearer <token>`（跟 tokenUrl 无关）

| 机制 | 何时 | 作用 |
| --- | --- | --- |
| `tokenUrl` | 仅 Swagger Authorize 弹窗 + 文档 | 告诉前端"去哪登录换 token" |
| `OAuth2PasswordBearer` | 每次请求（经 Depends） | 从请求头取 Bearer token |

> 所以真正每次执行的是 `Depends(oauth2_scheme)`，不是 `tokenUrl`。

---

### 6. 去掉 `tokenUrl="/api/v1/login"` 还能正常取到 token 吗？

**能。** `tokenUrl` 不影响"取 token/鉴权"（那靠 `OAuth2PasswordBearer` 读请求头）。

```python
oauth2_scheme = OAuth2PasswordBearer()   # 去掉 tokenUrl，也能正常取 token
```

- 代码/Postman 手动带 token → 正常
- Swagger Authorize 填账号密码自动换 → **不行**（不知道去哪个登录接口）
- Swagger Authorize 粘贴 token → 正常

> 结论：`tokenUrl` 只影响 Swagger "用户名密码自动换 token" 的便利性，不影响真正鉴权。
> 若只想"粘贴 token"，可用 `HTTPBearer`，更简单，完全不需要 tokenUrl。

### 7. 一次请求的完整调用链（step3）

以 `POST /api/v1/items` 为例：

```
uvicorn → app(main.py)
   → FastAPI 路由匹配（拼接 /api/v1 + /items + /）
   → 解析依赖 get_current_user（dependencies.py：取token→jwt.decode→鉴权）
   → 解析请求体 item: Item（Pydantic 校验）
   → 执行 create_item(item, user)
   → 按 response_model=Item 序列化
   → send() 返回 JSON
```

**路径拼接三层：**
```
app.include_router(api_router, prefix="/api/v1")   # ① /api/v1
  └─ api_router.include_router(items.router)        # ② /items
        └─ APIRouter(prefix="/items")
              └─ @router.post("/")                  # ③ /
```

> 最终地址：`/api/v1/items/`
